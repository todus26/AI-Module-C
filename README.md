## 2026-10-01

기본 수업 자료(강의 PDF, 프롬프트, 과제, 실습 파일)를 올려 두었고, 그날 직접 한 실습은 아래입니다.

- 실습 코드 Ch2: HTML 기본 구조와 스타일
- 실습 코드 Ch4: 파이썬 기초 (함수·람다 이전까지)
- `10.01수업내용`: HTML로 간단한 페이지 만들기

## 2026-10-02

프롬프트를 작성해 앱과 웹 서버를 만들어 보는 실습을 했습니다. 예시는 `KBA_AI/작업방`에 있습니다.

- 실습 코드 Ch4: 함수, 람다부터 이어서 진행
- `flask_test`: 첫 Flask 웹 서버
- `pdf다운로드`: PDF를 올리고 번역한 뒤 결과를 받는 웹 서버
- `pdf분할병합`: PDF를 나누고 합쳐 PDF 또는 Word로 저장하는 데스크톱 앱
- `아나바다`: 물건을 올리고 나누는 중고 거래 웹 서버
- `유튜브다운로드`: 유튜브 링크를 분석해 영상·음원을 받는 데스크톱 앱
