# 기술 스택
- GUI: PyQt5 (심플하고 직관적인 기본 수준의 UI 구성, 탭 방식 활용 권장)
- PDF 처리: 'pypdf' (또는 PyPDF2)
- PDF 미리보기(썸네일) 렌더링: 'pypdf'로는 썸네일 이미지 추출이 어려우므로 'PyMuPDF(fitz) ' 또는
  'pdf2image' 중 가볍고 구현이 쉬운 것을 선택해서 적용해 줘.

# 핵심 기능 요구사항

## 1. 분할 (Split) 기능
- PDF 파일 업로드: 단일 PDF 파일을 선택하여 업로드할 수 있어야 함.
- 썸네일 미리보기: 업로드된 PDF의 각 페이지를 썸네일 형태로 미리 볼 수 있는 UI를 제공해.
- 분할 옵션 선택:
  1) 범위 입력 (예: 1-5)
  2) 특정 페이지 입력 (예: 1, 3, 5)
  3) 고정 페이지 분할 (예: 2페이지씩 균등 분할)
- 중요 분할 조건: 사용자가 지정한 분할 범위에 포함되지 않은 '나머지 페이지'들도 버려지지 않고 따로 분할되어 저장되어야 해.
- 저장 위치: 원본 PDF가 있는 경로에 새로운 폴더를 생성하여 저장해.
  * 새 폴더명: '원제목_{분할된 총 파일 개수}' (예: document_3)
- 분할된 파일명 형식: '원제목_{분할된 페이지 정보}.pdf' (예: document_1-5.pdf, document_6-10.pdf 등)

## 2. 병합 (Merge) 기능
- PDF 다중 업로드: 여러 개의 PDF 파일을 한꺼번에 선택하고 업로드할 수 있어야 해 (목록 형태로 표시).
- 병합 실행: 업로드된 파일들을 하나의 PDF로 병합해.
- 병합 완료 미리보기: 병합이 완료되면, 완성된 PDF의 첫 페이지나 전체 썸네일을 미리보기로 보여주는 기능을 제공해.

# 추가 지시사항

- requirements.txt에 필요한 패키지 목록을 함께 출력해 줘.
- 에러 처리(예: 잘못된 페이지 범위 입력, 권한 부족 등)를 꼼꼼하게 적용해서 앱이 튕기지 않도록 해.

<웹 개발 실습1. PDF 번역: 프롬프트 만들기(완성) : LLM이 만들어준 프롬프트>

너는 파이썬 및 Flask 웹 개발 전문가야. 아래의 요구사항을 바탕으로 PDF 파일의 텍스트를 추출해 번역하고, 
결과를 텍스트 파일로 저장할 수 있는 웹 애플리케이션 코드를 작성해 줘.

1. 개발환경(기술 스택)
- Backend: Python, Flask
- PDF 텍스트 추출: pypdf (또는 PyPDF2)
- 번역 API: OpenAI API (openai 패키지)

2. 노드 설명(핵심 기능 요구사항)
1)  PDF 텍스트 추출 및 번역 연동:
   - pypdf를 이용해 업로드된 PDF 파일에서 '텍스트'만 추출해.
   - OpenAI API를 사용하여 추출된 텍스트를 선택한 언어로 번역해.
   - API Key는 절대 하드코딩하지 말고, 시스템 환경 변수에 저장된 ‘OPENAI_API_KEY’를 ‘os.environ’으로 불러와서 사용해.

2) 번역 진행률 표시 및 실시간 렌더링 (SSE):
   - 텍스트를 페이지 단위나 적절한 청크 단위로 나누어 번역을 진행해.
   - 번역이 진행되는 동안 왼쪽 패널의 진도율이 업데이트되고, 
     동시에 오른쪽 패널의 '번역된 내용' 영역에 텍스트가 실시간으로 추가되도록       SSE(Server-Sent Events)나 AJAX 폴링을 구현해.

3) 텍스트 파일(.txt) 저장 및 다운로드:
   - 번역이 완료되면 오른쪽 패널의 다운로드 버튼을 통해 번역된 텍스트 파일(.txt)을 받을 수 있게 해.
   - 다운로드되는 텍스트 파일의 이름은 업로드한 원본 PDF 파일의 이름과 동일하게 설정해      (예: ‘report.pdf’ 업로드 시 `report.txt`로 다운로드).

3. Ui설명(UX 및 화면 레이아웃 요구사항 - ChatGPT 스타일의 2단 분할 화면)
화면을 좌/우 두 개의 영역으로 분할하여 데스크톱에서 보기 좋게 구성해.

1) 왼쪽 패널 (컨트롤 및 진행 상태):
   - PDF 파일 업로드 폼
   - 번역 방향 설정 (영어 -> 한국어, 한국어 -> 영어 선택 라디오 버튼 또는 드롭다운)
   - '번역 시작' 버튼
   - 번역 진행률(%)을 실시간으로 보여주는 프로그레스 바 또는 텍스트

2) 오른쪽 패널 (미리보기 및 다운로드):
   - 'PDF에서 추출한 텍스트'를 보여주는 스크롤 가능한 미리보기 영역 (Textarea 또는 div)
   - '번역된 내용'을 보여주는 스크롤 가능한 미리보기 영역 (Textarea 또는 div)
   - 번역 완료 시 활성화되는 '다운로드' 버튼

3) 스타일링:
   - 배경이 어두운 색이면 글자 색깔을 흰색으로, 배경이 밝은 색이면 글자 색깔을 검은색으로 자동 적용되도록 CSS를 작성해.
   - 좌우 패널이 깔끔하게 나뉘도록 Flexbox나 Grid를 활용해 직관적으로 디자인해.

# 출력 지침
- ‘app.py’, ‘templates/index.html’ 코드와 필요한 폴더 구조를 명확히 나누어 작성해 줘.
- 코드를 실행하기 위해 설치해야 하는 ‘requirements.txt’ 내용과 터미널 실행 명령어도 함께 안내해 줘.

Flask와 Python을 사용하여 '아나바다(물품 공유 및 중고 거래)' 웹 애플리케이션을 개발해 . 
아래의 요구사항과 데이터베이스 구조를 바탕으로 필요한 모든 코드(app.py, models.py, HTML 템플릿 등)를 작성해 .

1. 기술 스택
- Backend: Python, Flask
- Database: SQLite 및 Flask-SQLAlchemy (ORM)
- Frontend: HTML, CSS (Bootstrap 5를 사용하여 깔끔하고 반응형으로 디자인), Jinja2 템플릿
- Image Handling: Flask-Uploads 또는 werkzeug.utils.secure_filename을 이용한 로컬 저장

2. 핵심 기능 요구사항
- 회원 관리: 사용자가 물품의 '등록자'가 되어야 하므로 간단한 회원가입 및 로그인/로그아웃 기능이 필요해 (Flask-Login 사용).
- 물품 CRUD: 사용자는 물품을 등록(사진 업로드 포함), 조회, 수정, 삭제할 수 있어야 해. 
  수정과 삭제는 해당 물품을 등록한 작성자만 가능해야 해.
- 물품 상세 정보: 제목, 사진(이미지), 상세 설명, 가격 정보가 들어가야 해.
- 가격 및 무료 나눔 처리: 가격을 입력받되, 가격이 '0'이거나 체크박스를 선택하면 '무료 나눔'으로 표시해.
- 물품 상태 관리 (추가 기능): 물품이 현재 '거래 중'인지 '나눔/거래 완료'인지 상태를 변경할 수 있는 버튼을 추가해.
- 검색 및 필터 (추가 기능): 메인 페이지에서 제목이나 내용으로 물품을 검색할 수 있고, '무료 나눔만 보기' 필터가 있으면 좋겠어.

3. 데이터베이스 모델 (Database Schema)
- User 모델:
  - id (Primary Key)
  - username (사용자 이름, Unique)
  - password_hash (비밀번호)
- Item 모델:
  - id (Primary Key)
  - title (물품 제목, String)
  - description (물품 설명, Text)
  - price (가격, Integer, 0이면 무료)
  - image_filename (업로드된 이미지 파일명, String)
  - status (상태: '거래가능', '거래완료' 등, String)
  - author_id (등록자, User 모델의 id를 참조하는 Foreign Key)
  - created_at (등록일, DateTime, 기본값 현재시간)
  - updated_at (수정일, DateTime, 수정 시 업데이트)

4. 디렉토리 구조 및 단계별 작업
- 프로젝트의 기본 디렉토리 구조를 먼저 제시해 줘.
- 그 다음, app.py 세팅, 데이터베이스 모델 구성, 라우팅, 
  그리고 프론트엔드 HTML(base.html, index.html, item_detail.html, item_form.html 등) 코드를 순서대로 제공해 줘.

<웹 개발 실습3. 영상 이미지 분석>
===============================================
파이썬과 yolo-11-namo 모델을 사용해 단순한 사물인식 웹을 만들어줘

# 1. 개발환경
- 웹서버: 파이썬. gradio 프레임워크를 사용한다.
- 인식실행: Ultralytics 패키지를 사용해 yolo모델을 실행한다.
- 영상처리: opencv python 라이브러리를 사용한다. 

# 2. 기능설명
- 이미지 입력: 사용자가 업로드한 이미지에서 yolo모델이 사물을 탐지하고,
  탐지된 위치에 바운딩 박스(경계박스)와 범주이름, 신뢰도를 표시한 결과이미지를 보여준다.
- 웹캠 입력: 웹캠 영상을 받아 프레임마다 객체를 인식하고, 바운딩 박스가 그려진 영상을 실시간으로 표시한다.

# 3. User interface
- 화면구성: 화면은 이등분한다. 좌측 50%, 우측 50%로 심플하면서도 직관적으로 구성한다.
   불필요한 장식은 하지 않는다.
- 좌측화면: 이미지 업로드 영역이다.
우측화면: 웹캠 업로드 영역이다.
