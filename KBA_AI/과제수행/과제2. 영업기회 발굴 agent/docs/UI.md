# UI: 영업기회 발굴 Agent

## 1. 방향

- 처음 보는 사람도 설명 없이 쓸 수 있는 직관적인 화면을 목표로 한다.
- 지도가 화면의 중심이고, 정보는 선택한 거래처에 대해서만 보여준다.
- 색상은 시프티블루 계열을 기본으로 하고, 장식 요소는 넣지 않는다.
- 화면의 문구에는 이모지를 쓰지 않는다.
- 프레임워크는 Streamlit을 기준으로 한다.

## 2. 화면 구성

```
+------------------------------------------------------------------+
| 상단 바: 서비스명                          데이터 기준일          |
+--------------+-----------------------------+---------------------+
| 사이드바      | 지도                         | 상세 패널            |
|              |                             |                     |
| 검색          |  핀 (노랑/초록/빨강)          | 거래처명, 상태       |
| 상태 필터     |                             | [요약][뉴스][보고서]  |
| 위치 미확인   |                             |                     |
| 거래처 목록   |  범례                        |                     |
+--------------+-----------------------------+---------------------+
```

| 영역 | 폭 기준 | 내용 |
|---|---|---|
| 사이드바 | Streamlit 기본 사이드바 | 검색, 상태 필터, 위치 미확인 거래처 목록 |
| 지도 | 본문의 약 2/3 | 거래처 핀, 범례 |
| 상세 패널 | 본문의 약 1/3 | 선택한 거래처의 요약, 뉴스, 보고서 탭 |

거래처를 선택하지 않았을 때 상세 패널에는 "지도에서 거래처를 선택하세요"를 표시한다.

## 3. 지도

### 핀 색상

| 상태 | 색상 | 범례 문구 |
|---|---|---|
| 신규 | 노랑 | 신규 거래처 |
| 일반 | 초록 | 일반 |
| 위험 | 빨강 | 위험 |

- 범례는 지도 한쪽에 고정하고, 각 상태별 거래처 수를 함께 표시한다.
- 색만으로 구분하지 않도록 툴팁과 상세 패널에도 상태 이름을 텍스트로 표시한다.
- 선택된 거래처의 핀은 크기를 키우거나 테두리를 두어 구분한다.
- 초기 지도 범위는 위치가 있는 모든 거래처가 보이도록 자동 맞춤한다.

### 호버 (요약 정보)

핀 위에 커서를 올리면 짧은 툴팁을 보여준다. 기본 항목은 다음과 같고, 실제 표시 항목은 `config.py`의 `TOOLTIP_FIELDS`로 바꿀 수 있다.

| 항목 | 비고 |
|---|---|
| 거래처명 | |
| 산업군 | |
| 상태 | 신규, 일반, 위험 |
| 최근 방문일 | customer_meeting 기준 |
| 최근 매출 | customer_sales 기준 |

툴팁은 4~5줄 이내로 유지한다. 요구사항에서 "특정 정보만" 보이게 하라고 했으므로 표시 항목은 확정이 필요하다.

### 클릭

핀을 클릭하면 해당 거래처가 선택되고 오른쪽 상세 패널이 갱신된다. 지도 위치와 확대 수준은 클릭으로 바뀌지 않게 한다.

## 4. 상세 패널

패널 상단에 거래처명과 상태 배지를 표시하고, 아래에 세 개의 탭을 둔다.

### 탭 1. 요약

| 구역 | 내용 |
|---|---|
| 기본 정보 | 위치, 산업군 등 customer_info의 주요 항목 |
| 매출 | 최근 매출, 주요 구매 품목, 간단한 추이 그래프 |
| 방문 이력 | 최근 방문일지 목록 (일자, 논의 내용, 요청사항) |
| 상태 근거 | 현재 상태로 분류된 이유 (예: 최근 매출 감소) |

### 탭 2. 뉴스

- customer_news에서 해당 거래처 관련 뉴스를 최신순으로 나열한다.
- 각 항목에는 제목, 날짜, 출처를 표시한다. 링크 정보가 있으면 링크를 연결한다.
- 항목마다 체크박스를 두어 보고서에 포함할 뉴스를 고를 수 있게 한다. 기본값은 전체 선택이다.
- 뉴스가 없으면 "관련 뉴스가 없습니다"를 표시한다.
- 하단에 "보고서 작성" 버튼을 둔다.

### 탭 3. 보고서

- "보고서 작성"을 누르면 생성 중 표시 후 초안을 보여준다.
- 초안은 편집 가능한 텍스트 영역에 표시하고, 항목은 Architecture.md의 출력 섹션을 따른다.
- 보고서에는 사용한 데이터의 출처를 표시한다.
- 하단에 다운로드 버튼을 둔다.
- 초안 위에 "자동 생성된 초안입니다. 내용을 확인하고 수정하세요."를 한 줄로 표시한다.

## 5. 사이드바

| 구역 | 내용 |
|---|---|
| 검색 | 거래처명 검색. 결과를 선택하면 지도가 해당 핀으로 이동하고 거래처가 선택됨 |
| 상태 필터 | 신규, 일반, 위험 선택. 선택한 상태만 지도에 표시 |
| 위치 미확인 거래처 | 위치 정보가 없는 거래처 목록과 건수 |

### 위치 미확인 거래처

- 사이드바 하단에 "위치 미확인 (N)"으로 접을 수 있는 목록을 둔다.
- 각 항목에는 거래처명과 상태를 표시한다.
- 항목을 선택하면 지도의 핀과 같은 방식으로 상세 패널이 열린다.
- 목록에서도 상태 필터가 동일하게 적용된다.
- 건수가 0이면 구역을 숨긴다.

## 6. 색상과 스타일

| 용도 | 값 | 비고 |
|---|---|---|
| 기본색 (시프티블루) | #4A6FA5 | 임시값. 정확한 색상 코드 확정 필요 |
| 기본색 진하게 | 기본색보다 한 단계 어둡게 | 제목, 선택 상태 |
| 기본색 연하게 | 기본색보다 한 단계 밝게 | 배경 강조, 탭 선택 |
| 배경 | 흰색, 연한 회색 | |
| 본문 글자 | 어두운 회색 | 순수 검정은 쓰지 않음 |
| 신규 | 노랑 | 핀, 배지 |
| 일반 | 초록 | 핀, 배지 |
| 위험 | 빨강 | 핀, 배지 |

- 색상 값은 `src/theme.py`에서만 정의하고, 다른 파일에서는 이 값을 참조한다.
- Streamlit 기본 테마는 `.streamlit/config.toml`의 `primaryColor`로 기본색을 맞춘다.
- 글꼴은 한글 가독성이 좋은 산세리프(Pretendard 또는 맑은 고딕)를 사용한다.
- 카드와 구분선은 얇은 선으로 처리하고 그림자와 그라데이션은 쓰지 않는다.
- 상태 색(노랑, 초록, 빨강)은 기본색과 어울리도록 채도를 낮춘 값을 사용하되, 지도 위에서 구분이 분명해야 한다.

## 7. 화면 문구

| 위치 | 문구 |
|---|---|
| 서비스명 | 영업기회 발굴 Agent |
| 지도 미선택 | 지도에서 거래처를 선택하세요 |
| 뉴스 없음 | 관련 뉴스가 없습니다 |
| 보고서 버튼 | 보고서 작성 |
| 보고서 생성 중 | 보고서를 작성하고 있습니다 |
| 초안 안내 | 자동 생성된 초안입니다. 내용을 확인하고 수정하세요. |
| 위치 미확인 | 위치 미확인 (N) |
| 데이터 오류 | 데이터를 불러오지 못했습니다. 파일명과 컬럼을 확인하세요. |

## 8. 상태별 화면

| 상황 | 처리 |
|---|---|
| 데이터 로드 중 | 지도 영역에 로딩 표시 |
| 파일 없음, 컬럼 불일치 | 어떤 파일의 어떤 컬럼인지 오류로 표시 |
| 위치 있는 거래처 없음 | 지도 대신 안내 문구를 표시하고, 위치 미확인 목록은 그대로 사용 |
| 필터 결과 없음 | "조건에 맞는 거래처가 없습니다" 표시 |
| 보고서 생성 실패 | 오류 메시지와 다시 시도 버튼 표시, 기존 입력은 유지 |

## 9. 확인이 필요한 항목

- 시프티블루의 정확한 색상 코드
- 호버 툴팁에 표시할 항목
- 요약 탭에 표시할 customer_info 컬럼
- 보고서 다운로드 형식
- 거래처 수 (수가 많으면 핀 클러스터링 적용 여부)
