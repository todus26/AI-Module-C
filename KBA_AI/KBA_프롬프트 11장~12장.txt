11장 실습 : 고객사 VOC 분석 Agent 구현

아래내용을 참고하여 crew AI로 고객사 VOC를 분석하는 에이전트 코드를 만들어줘

1. 환경
 - gradio 패키지를 이용해서 웹으로 구현
 - 그래프는 plotly 패키지 이용
 - OPENAI API-KEY는 나의 환경변수에 있음
 - 업로드 csv 파일 항목 : 순번, 일자, 고객명, 산업군, 지역, 제품명, 분야, 불만
 - 워드 클라우드, 그래프 출력시 한글이 안깨지도록 할 것
 - word 파일 생성시 한글이 안깨지도록 할 것
 - 하나의 .py 파일에 모든 기능 구현할 것.
 - 업로드한 requirements.txt 파일 참고하여 내 PC 환경의 패키지와 버전을 우선적으로 사용해 줘. 

2. agent 구성 : voc, issue, report
 1) voc agent
   - 역할 : csv 파일을 읽고 통계 분석, 시각화, 워드 클라우드 생성
   - 입력 : csv 파일
   - 출력 : 통계 데이터, 그래프, 워드 클라우드
   - 동작순서
     . csv 파일 로드 → 사용자의 선택에 따라 통계 분석, 시각화, 워드 클라우드 생성

  2) issue agent
    - 역할 : 산업군별 주요 voc를 분석, 주요 이슈와 개선 과제를 도출
    - 입력 : csv 파일
    - 출력 : 주요이슈, 개선과제
    - 동작순서
     . 산업군별 주요 voc 분석 → 주요 이슈 도출 → 개선과제 도출

  3) report agent
    - 역할 : voc 분석 보고서 워드파일 생성
    - 입력 : voc agent, issue agent 분석결과
    - 출력 : 보고서(산업군별, 분야별 voc 통계, 워드클라우드, 주요이슈, 대응방안)
    - 동작순서
     . 보고서 생성 → 사용자 다운로드

3. User interface
  1) 화면 구성 
    - 메뉴는 파일 업로드, 통계분석, 워드클라우드, 보고서생성으로 구성
    - 메뉴 클릭후 결과출력시 까지 진행사항, 로그 출력
  2) 메뉴별 동작
    - 파일 업로드 : 사용자가 csv 파일을 업로드, 결과 출력 화면에 데이터 출력
    - 통계분석 : 산업군, 제품명, 분야를 선택하면 해당 항목별 비율 막대그래프 출력
                   수치는 소수점 2째 짜리 까지 표현
    - 워드클라우드 : 불만 항목 중 키워드추출, 워드클라우드로 출력, 한글 안깨지도록 설정 
    - 보고서 생성 : 산업군별/분야별 voc 통계, 워드클라우드, 주요이슈, 대응방안 보고서 생성
                        워드파일 생성후 다운로드

12장 실습 1 : 재고관리 시스템 agent

소형창고의 재고관리 웹을 만들어줘

1. 개요
 - 파이썬 flask를 이용해줘, requirements.txt에서 패키지 버전을 확인해줘
 - 데이터베이스 항목은 ['일자', '분류', '제품명', '입출고', '수량', '최소재고량'] 이야

2. 화면 구성
- user inteface의 컬러는 연한 녹색, 연한 파란색, 연한 오렌지색으로 세련되게 만들어줘
- 첫화면을 2분할하는데 왼쪽이 20%, 오른쪽을 80% 비율로 만들어줘
- 첫화면 왼쪽에는 등록 메뉴(품목 등록, 입출고 등록), 조회 메뉴(재고현황, 품목별 입출고 현황)로 구성해
- 첫 화면의 오른쪽 상단에 "재고 관리" 라고 표시하고 재고 부족 품목 5건, 최근 입출고 
  현황 5건을 표시해줘
- 재고 부족 품목에 표시할 열은 (제품 등록일자, 분류, 제품명, 최소재고량, 현 재고량) 이야
- 최근 입출고 현황에 표시할 열은 (순번, 분류, 제품명, 입출고, 수량) 이야

3. 메뉴별 구성
- 왼쪽 품목 등록 메뉴를 누르면 (등록일자, 분류, 제품명, 초기수량, 최소 재고량)을 입력할
  수 있어야해
- 품목 등록시 분류 입력은 (케이블, 공구, 소모품, 기타)를 선택할 수 있도록 해줘
- 왼쪽 입출고 등록 메뉴를 누르면 제품명을 검색할 수 있게 해주고, 하단에는 제품 
  리스트를 보여줘
- 제품을 10개씩 보여줘 (순번, 등록일자, 분류, 제품명, 현 재고량), 그리고 페이지 뷰가 될 
  수 있도록 해줘
- 검색해서 제품명을 선택하거나, 제품명을 클릭시 입출고 등록 화면을 보여줘
- 입출고 등록화면에 (등록일자, 분류, 제품명, 입고/출고 선택, 수량)을 입력 할 수 있어야해
- 제품명은 선택하는 거니까 자동으로 들어가야 겠지 (분류도 자동 선택)
- 왼쪽 조회 메뉴에서 재고현황을 누르면 (순번, 최근입출고 일자, 분류, 제품명, 재고량, 
  최소 재고량)을 보여줘
- 재고량이 작은 순서로 10개씩 보여주고 페이지 뷰가 될 수 있도록 해줘
- 왼쪽 조회 메뉴에서 품목별 입출고 현황을 누르면 제품명을 검색할 수 있게 해주고, 
  하단에는 제품 리스트를 보여줘
- 제품을 10개씩 보여줘 (순번, 등록일자, 분류, 제품명, 현 재고량), 그리고 페이지 뷰가 될 
  수 있도록 해줘
- 제품명을 검색해서 선택하거나, 클릭하면 제품별 입출고 내역을 (순번, 등록일자, 분류, 
  제품명, 입고/출고, 수량, 재고량)  모두 보여줘야해

4. 기타
- 날짜는 "2025-07-17" 형식으로 자동 입력해줘
- 재고 관리에 필요한 기능이 있다면 추가해줘
- 관리자 로그인 "비밀번호 admin1004" 메뉴를 만들어 주고 로그인해서 들어가면
   분류를 추가, 제품명 수정, 최소 재고량 수정 등을 할 수 있게 해줘

12장 실습 2: 뉴스 수집 분석 Agent

아래 내용을 참고하여 serpapi를 통해 구글 뉴스, 네이버 뉴스를  수집해서
분석하는 에이전트 코드를 만들어줘

1. 환경
 - gradio 패키지를 이용해서 웹으로 구현
 - agent 구현은 LangGraph 패키지 이용
 - 그래프는 plotly 패키지 이용
 - serpapi api key는 .env 파일에 입력하도록 설정
 - OPENAI API-KEY는 나의 환경변수에 있음
 - 워드 클라우드, 그래프 출력시 한글이 안깨지도록 할 것
 - word 파일 생성시 한글이 안깨지도록 할 것


2. 노드 구성 : news, analyze, report
 1) news node
   - 역할 : serpapi에 접속해서 뉴스 수집
   - 입력 : 사용자가 입력하는 뉴스 키워드, 수집 건수, 구글뉴스/네이버 뉴스 선택
   - 출력 : 순번, 날짜, 제목, 주요내용, url 
   - 동작순서
     . 사용자가 키워드, 수집건수, 구글뉴스/네이버 뉴스 선택 입력
     . serpapi를 활용, '키워드'와 관련된 최신 뉴스를 '수집 건수' 만큼 수집
     . 순번, 날짜, 제목, 주요내용, URL을 json 으로 출력

 2) analyze node
    - 역할 : 수집한 뉴스에서 키워드, 시사점 도출 등
    - 입력 : news node의 출력
    - 출력 : 뉴스 그룹별 제목, 요약, 시사점
    - 동작순서
     . 뉴스에서 키워드를 도출하고 그룹핑
     . 그룹핑한 뉴스들의 제목을 정하고 1000자 이내로 요약, 주요 시사점 도출
     . 뉴스에서 주요 키워드를 도출하여 워드클라우드, 주요 단어의 발생 빈도로 그래프 생성

  3) report node
    - 역할 : analyze node의 출력을 워드파일로 생성
    - 입력 : analyze node 출력 
    - 출력 : 보고서(그룹핑한 뉴스 제목, 요약내용, 시사점, 키워드 그래프)
    - 동작순서
     . analyze node의 내용을 워드로 생성
     . 다운로드 메뉴를 보여주고 클릭시 사용자 지정 폴더에 저장
